# منصة تطوير وإعادة تأهيل وادي عدي

تطبيق مستقل داخل المستودع، مع مجلد وأصول وبيانات خاصة به. لا يستورد ملفات منصة Central-Design ولا يغيّر تطبيقها.

## التشغيل

افتح `index.html` أو استضف هذا المجلد كمسار مستقل على GitHub Pages. يعمل وضع المعاينة دون إعداد Firebase ويحتفظ بالتعديلات في المتصفح فقط.

## المزامنة السحابية

أكمل إعداد Web App العام في `firebase-config.js` (القيم الفارغة هي `apiKey` و`messagingSenderId` و`appId`). يحتاج التطبيق إلى إعداد Firestore وFirebase Authentication. يستخدم قاعدة البيانات `wadi-adai-db` ومجموعة بيانات جديدة مستقلة باسم `wadi_adai_v2`، ويقرأ التغييرات مباشرة باستخدام `onSnapshot`.

أنشئ حسابات أعضاء الفريق في Firebase Authentication، ثم أضف لكل عضو وثيقة `wadi_adai_v2_members/{uid}` تتضمن `{ "role": "editor", "active": true }`. للزوار القراءة فقط. لا تضع مفاتيح حساب خدمة أو كلمات مرور في GitHub.

قبل تمكين الكتابة، ادمج قواعد المساحة الجديدة في قواعد Firestore الحالية ولا تستبدل قواعد قاعدة البيانات كلها. المثال في `firestore-rules-snippet.txt` نطاقه محصور بمجموعات هذا المشروع. يجب كذلك ضبط قواعد Firebase Storage للسماح للفريق برفع الملفات إلى المسارات التي تبدأ بـ`wadi_adai_v2/`؛ من دون ذلك ستعمل السجلات النصية، لكن رفع المرفقات سيفشل. يحتفظ التطبيق الحالي وبياناته كما هي؛ هذا المشروع يستخدم مساحة منفصلة.

## حدود النسخة الحالية

المحتوى التأسيسي أُعيد بناؤه من المعاينة العامة للمنصة، بما يشمل المؤشرات والأهداف والمراحل ومحطات الرصد والمقترحات والتوصيات وخارطة الطريق ومعرضاً بصرياً توضيحياً. لم تتوفر ملفات المصدر أو صور المعرض الأصلية أو بيانات تصدير Firebase؛ لذلك لم تُنقل السجلات والصور الحية من مساحة النظام الحالي، ولم يتم تفعيل الاتصال السحابي قبل استكمال إعداد Web App ومراجعة قواعد Firestore وStorage.
